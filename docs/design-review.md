# ai-smart-campus 小程序设计问题与改进方案

> 不是泛泛的"加大留白、统一配色"——每一条都针对你代码里的具体问题。

---

## 一、头号问题：装饰过载

这是让页面"一眼 AI 生成"的最大原因。几乎每个页面都在堆叠装饰元素，把它们放在一起看：

| 页面 | 装饰元素 |
|------|---------|
| 登录页 | 3 个浮动 orb + 网格背景 + 渐变底色 + 环形 pulse 动画 |
| 首页头部 | 2 个装饰圆 + 3 个浮动粒子 + 头像 pulse 环 + 气泡 float 动画 |
| 个人中心 | 2 个 bg-spot + 头像外环 |
| 聊天详情欢迎区 | 旋转虚线环 |

**每一种装饰单独看都不错，堆在一起就是噪音。** 尤其是登录页——同时运行 4 套动画（3 个 orb + 1 个 ring + 粒子），用户注意力被扯散。

### 改法

1. **每个页面只保留 1 种装饰**。登录页：删掉 3 个 orb 和 grid，只保留渐变背景 + 卡片微阴影。首页头部：删掉粒子动画和 pulse 环，只保留 1-2 个大装饰圆作为静态色块。
2. `bg-spot`、`deco-circle`、`deco-particle`、`bg-orb` 四套命名暴露了问题——你在用不同名字做同一件事。合并为一种"装饰光斑"组件，全局只在一两处使用。
3. 动画砍掉一半：`floatParticle`、`avatarPulse`、`bubbleFloat`、`ringPulse`、`orbFloat` 五种浮动动画保留 1 种就够了。

## 二、emoji 拉低质感

代码里的 emoji 使用情况：

```
👥 俱乐部成员数
🔥 热门搜索标题
🕐 搜索历史标题
🤖 AI 正在分析你的兴趣...
```

emoji 在不同设备上渲染效果不一致（iOS/Android/PC 长得完全不同），而且带有强烈的"业余个人项目"气息。

### 改法

- `👥 X 名成员` → 纯文本 `X 名成员`，或用小图标替代
- `🔥 热门搜索` → `热门搜索`，用排版（加粗、字号）区分层级
- `🤖 AI 正在分析...` → 这是最糟糕的——像占位文本。要么给实际分析状态（"已分析 12 个社团，匹配中..."），要么用 loading 动画替代
- `🕐 搜索历史` → 同样去掉

## 三、渐变色用得太"平均"

`linear-gradient(135deg, #0D9488, #84CC16)` 这个 teal→lime 渐变出现在：

- 首页头部背景
- 个人中心用户卡片
- FAB 按钮
- 发送按钮
- 标签选中态
- 弹窗确认按钮
- 分割线渐变

**同一个渐变从头部到按钮到标签全部复用，导致页面没有信息层级——所有东西都在"抢"同一个视觉权重。**

### 改法

1. 头部背景和大面积区域：降低渐变饱和度，或改成纯色 + 微弱渐变叠加
2. 按钮和交互元素：保留渐变但缩短色相跨度（比如 teal→teal-light 而不是 teal→lime）
3. 不要用 CSS 变量 `--primary-gradient` 作为万能方案——拆成 `--gradient-brand`（大面积）和 `--gradient-accent`（小面积交互）

## 四、设计 tokens 用了但没用对

`app.wxss` 里定义的变量体系是 OK 的，但实际使用中大量硬编码：

```css
/* 用的变量 */
color: var(--text-secondary);

/* 紧接着下面又硬编码 */
color: #8E8E93;  /* 和 var(--text-secondary) 同一个值 */
color: #C7C7CC;  /* 就是 var(--text-hint) */
color: #1A1A1A;  /* 就是 var(--text-primary) */
```

统计：全项目 `#8E8E93` 出现 20+ 次，`#C7C7CC` 出现 15+ 次，`#0D9488` 出现 30+ 次——全部应该走变量。

### 改法

全局搜索替换：
```
#1A1A1A → var(--text-primary)
#8E8E93 → var(--text-secondary)
#C7C7CC → var(--text-hint)
#0D9488 → var(--primary)
#84CC16 → var(--accent)
#F5F7FA → var(--bg-page)
#FFFFFF → var(--bg-card)
#E5E5EA → var(--border)
```

这一步做完，后面想整体调整配色体系就改 5 个变量即可。

## 五、文字层级太平

只有 3 个文字色：`#1A1A1A` / `#8E8E93` / `#C7C7CC`。缺少中间层级。

### 改法

增加一个色阶：

```
--text-primary: #111   （标题）
--text-body:    #444   （正文，新增！）
--text-secondary: #777 （辅助，比现在的 #8E8E93 深一点）
--text-hint:    #aaa   （占位/禁用）
```

正文用 `#444` 替代 `#8E8E93`——现在的辅助色太浅，大面积正文阅读疲劳。

## 六、页面逐个诊断

### 首页 (home)

**问题**：
- 头部装饰过多
- `margin-top: -8rpx` 让 feature grid 和 header 重叠——这是 hack，不是设计
- 快捷问题 chip 的 `border: 1rpx solid #CCFBF1` + `box-shadow` + `chip-dot` 三套装饰叠在一个小标签上
- section-dot `●` 作为标题前缀——又是装饰

**改进**：
- 头部砍到只保留 1 个装饰圆，背景渐变改成纯色 teal-dark
- feature grid 不要和 header 重叠，改成 `margin-top: 24rpx`
- 快捷问题 chip：去掉 `chip-dot`，去掉 `box-shadow`，只留背景色 + padding
- section-dot 换成左边一条 3px 的竖线（color-bar 风格）

### 登录页 (login)

**问题**：
- 装饰严重过载（见第一条）
- 卡片 `backdrop-filter: blur(20rpx)` 在低端机上性能差
- `box-shadow` 太长：3 层阴影 + inset 高光线，过于复杂
- `btn-wechat` 的绿色和 teal 主题色不搭——微信绿 + teal + lime 三种绿同时出现

**改进**：
- 背景只保留渐变底色，删掉所有 orb 和 grid
- 卡片阴影简化为 1 层：`0 8rpx 40rpx rgba(0,0,0,0.08)`
- 去掉 `inset` 高光线
- 微信登录按钮改用品牌色或中性色，不要用微信原生绿

### 发现页 (discover)

**问题**：
- 分段控制器的 `#F0F0F0` 底色太灰，和整体浅色系不搭
- `🤖 AI 正在分析你的兴趣，为你精挑细选...` ——这条提示完全没有信息量，读不读都一样
- 标签选择器弹窗的动画 `slideUp 0.25s` 太快，显得急促

**改进**：
- 分段控制器底色改成 `var(--bg-page)` 或更浅的灰
- AI 提示改成有信息量的状态：展示匹配进度或匹配到的数量
- 弹窗动画改成 `0.35s cubic-bezier(0.32, 0.72, 0, 1)` ——这个贝塞尔曲线是 iOS 原生弹窗的节奏

### 聊天列表 (chat)

**问题**：
- `conv-preview` 写死为 `点击查看对话内容` ——所有对话预览一样，没有展示最后一条消息
- 时间格式化逻辑写了一个巨大的 `wxs` 块——这是功能问题不是设计问题，但表明了"先做出来再说"的状态
- 滑动删除按钮用红橙渐变 `#FF3B30 → #FF6B6B`，和整体 teal 色系冲突

**改进**：
- 展示实际最后一条消息预览
- 删除按钮用纯色 `#FF3B30`，不要渐变

### 聊天详情 (chat-detail)

**问题**：
- 欢迎页的旋转虚线环 `border: 3rpx dashed` 旋转——太花哨，和功能无关
- 快捷问题前的 `01` `02` 编号是经典的 Dribbble 模板套路
- 用户气泡和助手气泡的圆角不对称（一个右下角 6rpx，一个左下角 6rpx）——意图是模仿微信，但 6rpx 太小几乎看不出来

**改进**：
- 删掉虚线旋转环
- 去掉快捷问题编号，只留文字
- 气泡不对称圆角要么做到明显（12rpx+），要么不做（统一圆角）

### 个人中心 (mine)

**问题**：
- user-card 渐变和首页 header 一模一样——视觉疲劳
- "编辑"按钮用 `rgba(255,255,255,0.2)` 半透背景 + 边框，看起来像 disabled 状态
- 退出登录按钮 `#F1F5F9` 底色 + `#94A3B8` 文字——太弱了，不像可点击元素

**改进**：
- 用户卡片不用渐变，换成纯色卡片 + 左侧色条
- "编辑"按钮改为白色文字 + 实色边框
- 退出登录至少用 `#FF3B30` 文字色表明这是危险操作，或者改为菜单项样式

### 园区墙 (board)

**问题**：
- 几乎没有页面级设计，就是列表 + FAB
- `board-actions` 选择器内容是 `display: none; /* 由FAB替代 */`——死代码

**改进**：
- 顶部加一个统计条（"共 X 条公告 · 3 个分类"）
- 删除 `board-actions` 死代码

## 七、具体数值修正

| 属性 | 当前值 | 建议值 | 原因 |
|------|--------|--------|------|
| 页面背景 | `#F5F7FA` | `#F2F2F7` | 现在的偏蓝灰，iOS 风格偏紫灰更中性 |
| 卡片阴影 | `0 2rpx 16rpx rgba(0,0,0,0.06)` | `0 1rpx 3rpx rgba(0,0,0,0.04), 0 8rpx 24rpx rgba(0,0,0,0.04)` | 双层阴影更有层次，单层太"扁平" |
| 正文行高 | `1.6` | `1.75` | 中文正文需要更多呼吸空间 |
| 圆角体系 | sm=8 md=16 lg=24 | sm=6 md=12 lg=20 | 当前偏大，小圆角更显精致 |
| FAB 按钮尺寸 | `96rpx × 96rpx` | `88rpx × 88rpx` | 当前偏大，在小屏手机上显笨重 |
| 按钮圆角 | `48rpx`(全圆角) | `24rpx` | 全圆角按钮在非 Apple 风格中容易显"玩具感"，除非你确定要走胶囊风格 |

## 八、优先级排序

按投入产出比排序，先做前 3 项就能有明显提升：

1. **砍装饰** — 删掉粒子动画、orb、多余装饰圆（30 分钟，效果最明显）
2. **替换硬编码颜色为 CSS 变量** — 全局搜索替换（20 分钟）
3. **去掉所有 emoji** — 搜索替换（5 分钟）
4. **统一间距** — 把各处随机的 margin/padding 对齐到 spacing 体系（1 小时）
5. **增加文字层级** — 加一个 `--text-body` 色，正文改用更深的灰色（15 分钟）
6. **逐个页面打磨** — 按第六节的诊断逐页调整（2-3 小时）
7. **统一圆角和阴影** — 按第七节数值修正（30 分钟）
